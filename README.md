# Home-Assistant-Add-ons

Eigene Add-ons für Home Assistant OS / Supervised.

[![Repository hinzufügen](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fsitaro%2Fha-addons)

| Add-on | Beschreibung |
|---|---|
| [iPhone Backup](iphone_backup/) | Verschlüsselte iPhone-Backups per WLAN (pymobiledevice3), Ablage direkt in OneDrive (rclone) |

Installation: *Einstellungen → Add-ons → Add-on-Store → ⋮ → Repositories* → `https://github.com/sitaro/ha-addons` hinzufügen.
